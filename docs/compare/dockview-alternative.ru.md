# dockview или wmkit

dockview — очень хороший менеджер докинга, и для части приложений он подходит лучше, чем wmkit. Библиотеки начинают с противоположных концов. dockview начинает с закреплённого рабочего места из панелей и позволяет группе плавать или выйти в отдельное окно браузера. wmkit начинает со свободных окон — открыть, свернуть, развернуть, прилепить, сложить стопкой, переключить — и позволяет окну закрепиться. Ответ зависит от того, на каком конце живёт ваше приложение.

Сведения о dockview на этой странице сверены с его документацией и репозиторием в ноябре 2026 года.

## Бок о бок

| | dockview | wmkit |
| --- | --- | --- |
| Чем является в первую очередь | раскладка с докингом: сетки, разделения, группы вкладок | оконный менеджер: плавающие окна с полным жизненным циклом |
| Докинг с разделениями и вкладками | ядро библиотеки | плагин `dock` |
| Плавающие панели | плавающие группы поверх раскладки | любое окно, со сворачиванием, разворачиванием, восстановлением и слоями |
| Вынос в отдельное окно браузера | да, группы выносятся | `popout`: Picture-in-Picture или всплывающее окно |
| Снэп к половинам, четвертям, третям, меню раскладок | — | встроено, плюс `layouts` |
| Панель задач, переключатель окон, обзор | — | `taskbar`, `switcher` |
| Рабочие столы | — | встроено |
| Undo и redo | редакция Enterprise | в ядре под MIT, целое перетаскивание — один шаг |
| Фреймворки | React, Vue, Angular, чистый TypeScript | React, Vue, Svelte, Solid, Angular, Preact, Lit, Qwik, веб-компоненты, без фреймворка |
| Лицензия | ядро под MIT, коммерческая редакция Enterprise | MIT, целиком |
| Зависимости | нет | нет |

## Берите dockview, когда

- приложение и **есть** рабочее место: почти всё почти всегда закреплено, как в IDE или торговом терминале с постоянными панелями;
- нужно то, что его докинг умеет сверх базового, например вложенные сетки с тонким управлением каждой группой или возможности редакции Enterprise;
- плавание — исключение: панель вытащили на минуту.

## Берите wmkit, когда

- окна по умолчанию плавают, а расставляет их пользователь: веб-десктоп, дашборд из виджетов, инструменты поверх холста, консоль поддержки;
- окнам нужна собственная жизнь: сворачивание в панель задач, разворачивание, снэп бок о бок, Alt+Tab, несколько рабочих столов, вопрос перед закрытием;
- часть окон закрепляется, а остальные продолжают плавать над доком;
- каждое действие должно работать с клавиатуры и озвучиваться, а undo — покрывать их все;
- на странице Svelte, Solid, Preact, Lit или Qwik, нет фреймворка вовсе или их сразу несколько.

## Докинг в wmkit

```js
import { attachDesktop, createWindowManager } from '@surdeddd/wmkit'
import { createDock } from '@surdeddd/wmkit/dock'

const wm = createWindowManager()
const desktop = attachDesktop(wm, document.querySelector('#desktop'))
const dock = createDock(desktop)

wm.open({ id: 'editor', title: 'main.ts' })
wm.open({ id: 'files', title: 'Files' })
dock.dock('editor')
dock.dock('files', { side: 'left' })
```

Закреплённое окно остаётся окном: оторвите его — и оно плавает, отмените — и оно снова в своей панели, а `persist` сохраняет оба состояния.
