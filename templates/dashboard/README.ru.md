# Шаблон дашборда на wmkit

[English version](./README.md)

Операционный дашборд на [wmkit](https://github.com/Surdeddd/wmkit): четыре панели — ключевые цифры, живой график выручки, таблица заказов и журнал событий — разложены плагином докинга. Тащите панель за заголовок, чтобы закрепить её в другом месте, или бросьте её в середину другой панели, чтобы сложить их вкладками. С зажатым Shift или с включённой кнопкой **«Не закреплять»** на панели инструментов (так это делается на сенсорном экране) панель останется плавающей. Разделители меняют размеры панелей. **«Сбросить раскладку»** заново открывает закрытые панели и ставит каждую на своё место одним шагом отмены. Раскладка сохраняется в `localStorage` и возвращается после перезагрузки.

[![Открыть в StackBlitz](https://developer.stackblitz.com/img/open_in_stackblitz.svg)](https://stackblitz.com/github/Surdeddd/wmkit/tree/main/templates/dashboard)

## Запуск

```bash
npx degit Surdeddd/wmkit/templates/dashboard my-dashboard
cd my-dashboard
npm install
npm run dev
```

Шаблону нужен `@surdeddd/wmkit` версии 0.13 или новее.

## Что внутри

- `<wm-desktop>` и `<wm-window>` из `@surdeddd/wmkit/elements`: панели — обычный HTML, без фреймворка. У панелей, сложенных вкладками, появляется полоса вкладок; с клавиатуры вкладки переключают Ctrl/⌘ + Alt + PageUp/PageDown. Закрытая панель остаётся закрытой и после перезагрузки, пока её не вернёт «Сбросить раскладку».
- `createDock()` из `@surdeddd/wmkit/dock`: раскладка по умолчанию, отрыв панелей, повторное закрепление, вкладки, разделители с управлением с клавиатуры и опция `float`, связанная с кнопкой «Не закреплять».
- `persist="wmkit-dashboard"` на рабочем столе: окна и раскладка переживают перезагрузку, и панели стоят на местах с первого кадра, даже если размер окна изменился.
- Четыре темы, импортированные по одной из `@surdeddd/wmkit/themes`: `glassTheme` оформляет страницу, а `glassShadowTheme`, переданная в `desktop.styles`, — заголовок и содержимое внутри теневого корня каждой панели (поэтому у retro синий заголовок и вдавленное содержимое). В сборку попадают только эти четыре темы.
- Интерфейс на английском и русском: язык берётся из `navigator.language`, есть переключатель.
- Линейный график на чистом SVG, без библиотек графиков.

## Где что менять

| Файл | Что в нём |
| --- | --- |
| `index.html` | четыре панели и панель инструментов |
| `src/main.ts` | раскладка по умолчанию, смена темы, кнопка «Не закреплять», переключатель языка, цикл обновления |
| `src/panels.ts` | отрисовка плиток, графика, таблицы и журнала |
| `src/i18n.ts` | все строки на английском и русском |
| `src/style.css` | стили страницы и панелей; отступы внутри панелей уже задаёт тема |
